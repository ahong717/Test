01 / 核心規劃思維

OS 與資料徹底分離

不要將作業系統裝在大容量硬碟中。使用獨立的 SSD 作為系統盤，這意味著即使系統崩潰重裝，你的硬碟陣列資料依然紋絲不動。

運算與儲存分工

N100 主機負責 24/7 的輕量運算與網路管理（如 VPN）；UGREEN DXP4800 則專職穩定的大容量存儲，將職責切分才能達到最長久的穩定。

03 / 網路先行：UniFi VPN

為什麼重要？

在部署 NAS 的過程中，你可能會出門或遠離主機。先架設好 VPN，確保即使你不在主機旁，也能隨時通過 iPhone 連入內網進行 SSH 救援。

1

UniFi 控制台設定

進入 Settings > Teleport & VPN > VPN Server > Create New (WireGuard)。
監聽埠固定為 51820 (UDP)。

2

AllowedIPs 選項思維

這是新手最容易出錯的地方。根據你的需求修改設定：

模式 A：全流量轉發 (翻牆)
AllowedIPs = 0.0.0.0/0

手機所有上網流量都會經過家裡主機。

模式 B：僅存取家裡內網
AllowedIPs = 192.168.1.0/24, 192.168.10.0/24

手機只有連內網設備時才走 VPN。

04 / 實戰初始化指令

當你完成 OMV 8 系統安裝後，請透過 SSH 依序貼上以下指令進行優化：

Step 1 系統升級與 OMV-Extras

這是開啟 Docker 功能的關鍵步驟。

COPY
# 更新源並升級系統
sudo omv-upgrade

# 安裝社群外掛腳本 (OMV-Extras)
wget -O - https://github.com/OpenMediaVault-Plugin-Developers/installScript/raw/master/install | sudo bash

Step 2 修正 Postfix 報錯

針對 OMV 8 常見的郵件服務卡關，執行強制部署：

COPY
sudo omv-salt deploy run postfix

Step 3 硬碟規劃與權限自動化

! 注意：指令中的 /srv/data 應換成你實際在 OMV 掛載的 UUID 路徑。

COPY
# 建立種子下載與媒體庫目錄
mkdir -p /srv/data/torrent/{watch,incomplete,complete}
mkdir -p /srv/data/{media,backup}

# 一次性修正權限：確保 Docker 與 SMB 都能正常寫入
chown -R root:users /srv/data
chmod -R 2775 /srv/data
